# Security Policy

## Supported Versions

`tja-ai-chartgen` is pre-1.0 software. Security fixes are handled on the current `main` branch.

## Reporting a Vulnerability

Please do not open a public issue for secrets exposure, unsafe file handling, or other security-sensitive reports.

If GitHub private vulnerability reporting is enabled for the repository, use that channel. Otherwise, contact the maintainer through the GitHub profile for `vibub` and include:

- affected version or commit
- reproduction steps
- expected impact
- any relevant generated files with secrets removed

Do not include real API keys, private audio files, or credentials in reports.
